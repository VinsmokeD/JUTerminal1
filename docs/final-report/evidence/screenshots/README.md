## Capture Rules

- Use the current application only (final Parallax branding, not CyberSim).
- Use the same viewport family for related screenshots (1440 × 900 recommended).
- Hide or blur tokens, emails, hashes, and credentials.
- Prefer PNG format.
- Name files with lowercase kebab-case.
- Add every screenshot to the figure list and Canva asset checklist.
- After capture, update the Status column above to ✅ Captured.
