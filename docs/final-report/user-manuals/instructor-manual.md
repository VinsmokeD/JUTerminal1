# CyberSim Instructor Manual

## 📋 Overview
CyberSim provides instructors with a high-level view of student performance, methodology adherence, and learning outcomes.

### 1. Instructor Dashboard
*   **Class Metrics**: View aggregate scores across all students.
*   **Weak Points**: Identify which PTES/OWASP phases students struggle with most.
*   **Hint Usage**: Monitor which scenarios require the most AI assistance.

### 2. Session Monitoring
*   **Live View**: (If enabled) View active student sessions.
*   **Report Review**: Access student-generated reports for grading.
*   **Grade Export**: Download CSV/Excel data ready for integration with university LMS.

## 📈 Learning Analytics
CyberSim tracks:
*   **Methodology Gating**: How often students try to skip phases (e.g., exploitation before recon).
*   **Detection Coverage**: For Blue Team students, how many of the "ground truth" alerts were identified.
*   **Time-to-Detect**: Latency between a Red Team action and Blue Team triage.

## ⚙️ Administration
*   **Scenario Management**: Reset scenario states or modify flag values (requires admin access).
*   **System Health**: Monitor Docker resource consumption and Elastic SIEM status.
