The platform was renamed from **CyberSim** to **Parallax** on 2026-05-31.

**Why:** User wanted a more premium, professional brand name. "Parallax" encodes the dual red/blue perspective concept of the platform.

**How to apply:** Always refer to the platform as "Parallax" — never "CyberSim." All code, docs, and filenames reflect Parallax. The nav component is now `ParallaxNav.jsx`.
